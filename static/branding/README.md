# Agamemnon identity assets

The Agamemnon application mark and its Agents control-room representation are deliberately different assets.

- `agamemnon-trojan-helmet.svg` is the product mark: a polished Trojan/Greek helmet in unmistakable side profile. It is used for the Agamemnon favicon, login, sidebar, welcome state, the shared navigation in Chat, Agents, and Workbench, and the Classic-style Phalanx window title. Inside the app (`.brand-crest-icon` in `static/style.css`) the file is applied as a CSS mask, so the crest takes the active brand color (theme accent or the Customize "Agamemnon crest" color) in both page styles; the file's own gold fill remains the favicon/login color. Source: `game-icons:spartan-helmet` by Delapouite, CC BY 3.0, selected from the high-quality vector family shown in the supplied Penpot identity review.
- `agamemnon-agent-marks.svg` is the Phalanx/control-room sprite sheet. It contains five genuinely different silhouettes: `#soldier-primary` (mounted commander), `#soldier-worker` (standing spear-bearing pikeman), `#soldier-scout` (ranged bowman), `#soldier-reviewer` (charging shield-bash pose), and `#soldier-specialist` (paired guards). The runtime chooses geometry from the operational role and independently applies model identity through `currentColor` (default gold, Anthropic coral, OpenAI mint, Google blue, Mistral amber, local purple). Color is therefore an accent, not the only distinction. Status, role, model, and unit number remain explicit text.

A parent agent can choose a persistent override from seven variants in its detail panel: mounted commander, pikeman, bowman (`#soldier-scout`), shield charger, paired guards, sword fighter (`#soldier-sword`), and crested guard (`#soldier-helmet`). Automatic preserves the prior role silhouette. The choice is stored under `agamemnon_soldier_appearance` in that parent session's settings; model-driven color and non-Agamemnon themes remain unchanged. Sword fighter uses [Swordman by Cathelineau](https://game-icons.net/1x1/cathelineau/swordman.html), CC BY 3.0; the new crested guard is [Spartan by Lorc](https://game-icons.net/1x1/lorc/spartan.html), CC BY 3.0. The selector appears in `website/agamemnon-appearance-preview.html`.

The soldier is used only by generated agent representations in the Agents control room. Chat and Workbench retain the helmet branding in their shared navigation but do not repeat a soldier sprite in contextual identity rows. Odysseus retains its prior role seals, layout, installed-app raster marks, and manifest identity.
